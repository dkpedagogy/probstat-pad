# 확률과 통계 필기 학습

## 학생 진입

`site/index.html`을 Safari에서 연다. 학생 이름과 암호를 입력하면 문항 목록이 열린다. `config.js`의 `passHash`는 암호 원문이 아니라 SHA-256 hex 값이다. 샘플 설정의 암호는 제작 검증용으로 학생 `student`, 교사 `teacher`를 사용한다. 실제 배포 전에 `scripts/make_hash.html`로 해시를 생성해 교체한다.

문항을 열고 Apple Pencil로 필기한다. 캔버스에는 펜 입력만 기록하며 손가락 입력은 무시한다. 개발용 마우스 입력은 주소 뒤에 `?debug=1`을 붙인 경우에만 기록한다. 제출 뒤 정오, 선택 비율, 난이도, 해설 열람, 유사문제 요청을 기록한다. 설정에서 세션 JSON을 내려받을 수 있다.

## 교사 진입

`site/teacher.html`을 연 뒤 교사 암호를 입력한다. 학생이 내보낸 JSON 파일을 `JSON 파일 열기`로 불러오거나, Worker가 연결된 경우 서버 목록을 불러온다. 세션을 고르면 문항별 표, 오답과 어려움 모음, 요청문 복사, CSV 내보내기, 획 재생을 사용할 수 있다.

## 데이터 흐름

필기 획은 `{id, tool, color, width, t0, t1, points}` 벡터 배열로 IndexedDB에 즉시 저장한다. 문항 기록에는 시간 순서 이벤트, 제출 답, 자기평가, 해설 열람, 요청문, idle·erase_burst 막힌 구간이 함께 저장된다. `syncUrl`이 비어 있지 않으면 30초 주기와 문항 닫힘 시점에 `/api/log`로 변경 기록을 전송한다. 전송 실패 기록은 다음 주기에 재시도한다.

## 한계

문항과 해설 이미지는 제작 검증용 placeholder이다. 브라우저가 IndexedDB를 제한하는 개인 정보 보호 모드에서는 저장이 제한될 수 있다. 서버 사용 시 암호 해시와 Worker 비밀값을 교체하고 `ALLOWED_ORIGIN`을 사이트 주소로 제한해야 한다. 네트워크가 없는 경우 서버 전송은 되지 않지만 로컬 저장과 JSON 내보내기는 동작한다. 화면·필기·이미지 확대의 실제 iPad Safari 검증은 이 환경에서 미확인이다.
